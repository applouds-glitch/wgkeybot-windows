# WgKeyBot для Windows

WireGuard VPN клиент с TURN/DTLS прокси и авторизацией через ВКонтакте.

Нативное окно Windows со статусом подключения и работой в системном трее.
Один `.exe` файл + wintun.dll.

## Скачать

[Последний релиз](https://github.com/applouds-glitch/wgkeybot-windows/releases/latest) — выберите `.zip` для вашей архитектуры (amd64, x86, arm64).

В архиве `wgkeybot.exe` и `wintun.dll`. Положите оба файла в одну папку.

## Быстрый старт

1. Получите токен у бота [@wg_key_bot](https://t.me/wg_key_bot) в Telegram
2. Запустите `wgkeybot.exe` (подтвердите запрос UAC — права администратора нужны для VPN режима)
3. В стартовом окне нажмите **Импорт токена…** и вставьте токен
4. Выберите **VPN** или **SOCKS5 прокси** и нажмите **Подключить**

## Главное окно

При запуске открывается окно со следующими данными:

- Состояние подключения, ожидание ответа WireGuard или восстановление связи.
- Выбранный режим VPN/SOCKS5; в режиме прокси — локальный адрес и порт.
- Получено, отправлено, суммарный трафик и время текущего соединения.
- Сервер, адрес интерфейса, DNS, MTU, маршруты и время проверки конфига.
- Импорт и обновление конфига, автоподключение и автоматическое обновление.

Счётчики берутся из WireGuard и обновляются раз в секунду. После отключения
показан итог последнего соединения; новое подключение, включая переподключение
watchdog, сбрасывает счётчики. Это локальная статистика соединения, а не расход
или остаток тарифного лимита на сервере; между запусками она не сохраняется.
Ключи WireGuard и токен в сведениях о конфиге не отображаются.

Закрытие окна оставляет приложение в трее. Открыть его снова можно через
**Открыть WgKeyBot** в меню трея или повторным запуском `.exe`.
Для полного завершения используйте **Выход** в трее. Режим можно сменить после
отключения. Если конфиг обновлён в фоне, окно показывает активный конфиг и
отметку об обновлении для следующего подключения.

## Режимы работы

### VPN режим (по умолчанию)

Весь системный трафик идёт через туннель. Нужны права администратора — создаётся виртуальный сетевой адаптер (wintun), системные маршруты настраиваются автоматически.

### SOCKS прокси режим

Запускает локальный SOCKS5-сервер на `127.0.0.1:1080` (порт настраивается в меню). Права администратора **не нужны**. Отдельные приложения проксируются вручную — системный трафик остаётся прямым.

Поддерживаются:
- **CONNECT** — TCP-соединения (HTTP, HTTPS, SSH и т.д.)
- **UDP ASSOCIATE** — UDP через туннель (голосовые звонки, игры)
- DNS резолвится удалённо (socks5h) — утечек DNS нет

#### Подключение Telegram

В настройках Telegram:
**Настройки → Конфиденциальность и безопасность → Прокси-сервер → Добавить прокси**

| Поле | Значение |
|------|----------|
| Тип | SOCKS5 |
| Хост | 127.0.0.1 |
| Порт | 1080 |

Нажмите **Сохранить** → Telegram переключится на туннель. В статусе появится задержка до прокси.

#### Подключение Chrome

Вариант 1 — запустить Chrome с флагом (рекомендуется, не затрагивает другие браузеры):

```bat
chrome.exe --proxy-server="socks5://127.0.0.1:1080" --host-resolver-rules="MAP * ~NOTFOUND , EXCLUDE 127.0.0.1"
```

Вариант 2 — расширение [Proxy SwitchyOmega](https://chromewebstore.google.com/detail/proxy-switchyomega/padekgcemlokbadohgkifijomclgjgif):
- Создайте профиль: протокол **SOCKS5**, сервер `127.0.0.1`, порт `1080`
- Активируйте профиль — трафик браузера пойдёт через туннель

#### Другие приложения

Любое приложение с поддержкой SOCKS5 прокси подключается аналогично:
- **curl**: `curl --socks5-hostname 127.0.0.1:1080 https://example.com`
- **Python requests**: через библиотеку `PySocks` или `httpx`
- Системный прокси Windows: Параметры → Сеть → Прокси → Ручная настройка (только для приложений, уважающих системный прокси)

## Меню трея

| Пункт | Описание |
|---|---|
| Открыть WgKeyBot | Открыть окно состояния, конфига и статистики |
| Подключить | Подключиться с сохранённым конфигом |
| Отключить | Остановить туннель |
| Импорт токена... | Получить конфиг по токену |
| Обновить конфиг | Запросить конфиг по сохранённому токену; если он не изменился, туннель не переподключается |
| Подключаться при запуске | Автоматический подъём туннеля при старте |
| Обновлять конфиг автоматически | Раз в 12 часов проверять конфиг через поднятый туннель; новый вступает в силу при следующем подключении |
| Режим → VPN | Весь трафик через туннель |
| Режим → SOCKS прокси | Локальный SOCKS5 без захвата системы |
| О программе | Версия и информация |
| Выход | Отключиться и закрыть программу |

## Как это работает

```
Приложение → [wintun / userspace netstack] → TURN/DTLS прокси → TURN сервер → WireGuard сервер → Интернет
```

- WireGuard туннель на userspace реализации (wireguard-go)
- TURN/DTLS для обхода NAT и защиты от DPI
- Авторизация через VK OAuth
- Watchdog: автоматический переподъём туннеля при зависшем handshake

## Сборка из исходников

```bash
go install github.com/josephspurrier/goversioninfo/cmd/goversioninfo@latest
go run ./cmd/genico
GOARCH=amd64 goversioninfo -o rsrc_windows.syso versioninfo.json
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H windowsgui" -o wgkeybot.exe .
```

Главное окно, импорт токена и сообщения используют Win32 и системные элементы
управления. Для них не нужны PowerShell, .NET, CGO или веб-интерфейс.
WebView2 по-прежнему используется только для капчи с существующим браузерным
fallback. Масштабирование окна и шрифтов учитывает DPI монитора.

GitHub Actions проверяет кросс-сборку из Linux для `amd64` и `386` с флагами
релиза, а на Windows запускает тесты состояний экрана и настоящих Win32-контролов
для обеих архитектур. Публикация релизов остаётся в `release.yml`.

### Иконки

- **Иконка приложения** — бирюзовый бот с золотым ключом на тёмной плитке.
  `assets/icon.ico` содержит размеры 16, 20, 24, 32, 40, 48, 64, 128 и 256 px;
  `assets/icon.png` — превью 512 px. Каждый размер рисуется отдельно из
  геометрии в `assets/icon.go` и `assets/glyph.go`, без уменьшения иллюстрации.
- **Иконки трея** — тот же бот с контрастным контуром для светлой и тёмной
  панели, в размерах 16…64 px. Состояния различаются цветом и символом:
  мятная галочка — подключено, янтарные точки — подключение, серый минус —
  отключено. При подключении пульсирует янтарный акцент. Готовые ICO
  кэшируются, поэтому анимация не перерисовывает их на каждом шаге.
- После изменения рисунка пересоберите файлы и ресурс Windows:

  ```bash
  go run ./cmd/genico                          # пересобрать icon.ico и icon.png
  go run ./cmd/genico -preview /tmp/wgkeybot-icons  # HTML-галерея и PNG всех размеров
  GOARCH=amd64 goversioninfo -o rsrc_windows.syso versioninfo.json  # ресурс для amd64
  ```

  Для x86 задайте `GOARCH=386`. CI пересоздаёт иконки и
  встраивает ресурс перед сборкой каждой архитектуры.

WireGuard VPN client with TURN/DTLS proxy and VK authentication.

System tray app for Windows. Supports two modes:
- **VPN** — full system routing via wintun adapter (requires admin)
- **SOCKS5 proxy** — local proxy on `127.0.0.1:1080`, no admin required; configure per-app (Telegram, Chrome, curl, etc.)
